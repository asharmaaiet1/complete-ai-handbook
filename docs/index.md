# Complete AI Handbook

## Understand AI. Build AI. Engineer AI.

Welcome to the **Initial Public Preview** of Complete AI Handbook. This documentation site contains five published lessons about AI fundamentals and a reference-oriented [Mathematics for AI roadmap](mathematics-for-ai/index.md).

Start with [AI fundamentals](start-here/README.md), explore the [Mathematics for AI roadmap](mathematics-for-ai/index.md), follow the [learning paths](learning-paths.md), or read the [project roadmap](https://github.com/asharmaaiet1/complete-ai-handbook/blob/main/ROADMAP.md) for planned work. Planned areas are not yet completed lessons.

The project aims to combine theory with practical implementation for software developers. This preview does not yet include runnable Python or TypeScript examples. Check each lesson's status and references before relying on it.
